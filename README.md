# Brass Barbershop — шаблон сайта барбершопа

Демо-сайт мужского барбершопа. Название, адрес, телефон, цены и отзывы вымышленные,
вместо фотографий стоят латунные иллюстрации (`images/*.svg`).
Без сборки и зависимостей: HTML, CSS и JavaScript открываются как есть.

Адрес в тегах `canonical`, `og:url` и в `sitemap.xml` рассчитан на публикацию через GitHub Pages
в репозитории `barbershop-template`: https://tsum323.github.io/barbershop-template/

## Как настроить под нового клиента

1. Название: найдите `Brass Barbershop`, `BRASS` и `Brass` во всех файлах
   (логотип в `style.css` — свойство `content: "BRASS"` у `.hero-image::after`).
2. Адрес `ул. Примерная, 1` и телефон `+7 900 000 00 00` / `79000000000` — во всех `.html` и в `script.js`.
3. Карта на `contacts.html`: замените `src` у `iframe` на виджет Яндекс Карт с адресом клиента.
4. Отзывы на главной: вместо карточек-примеров вставьте виджет отзывов Яндекс Карт
   (`https://yandex.ru/maps-reviews-widget/<ID организации>?comments`).
5. Фото: положите снимки клиента в `images/` и замените пути `images/*.svg`; заполните `alt`.
6. Уберите из подвала пометку «демо-сайт…».

## Демо-версия закрыта от поисковиков

На всех страницах стоит `<meta name="robots" content="noindex, nofollow">`.

Для сайта настоящего клиента:
1. удалите эту строку (и комментарий над ней) из всех `.html`, кроме `404.html`;
2. в `robots.txt` раскомментируйте строку `Sitemap: ...`;
3. добавьте сайт в Яндекс Вебмастер и отправьте `sitemap.xml`.

## Структура

| Файл / папка | Что внутри |
|---|---|
| `index.html` | Главная |
| `services.html` | Услуги и цены, спецпредложения |
| `barbers.html` | Мастера |

| `robots.txt`, `sitemap.xml` | Для поисковых систем |

## Как поменять частые вещи

**Телефон** — встречается в каждом файле `.html` (шапка окна записи — в `script.js`).
Найдите поиском `79000000000` и `+7 900 000 00 00` и замените во всех файлах.
В `index.html` телефон есть ещё в блоке `application/ld+json` (данные для поисковиков).

**Цены** — `services.html` (блок `price-list`) и `index.html` (блок `services-grid`).
Меняйте в обоих местах.

**Фото** — положите файл в `images/` (лучше WebP, ширина до 1600 px) и замените путь в `src`.
SVG-иллюстрации после замены можно удалить.
Обязательно заполните `alt` — короткое описание того, что на фото.

**Цвета** — в начале `style.css`, блок `:root` (`--color-accent` — латунь, `--color-bg` — фон).

## После любого изменения CSS или JS

Увеличьте номер версии в ссылках на файлы во **всех** `.html`, например
`style.css?v=20261015` → `style.css?v=20261022`.
Иначе посетители до 10 минут могут видеть старую версию из кэша.

## Если подключается свой домен

1. Добавьте файл `CNAME` с доменом и настройте DNS по инструкции GitHub Pages.
2. Замените `https://tsum323.github.io/barbershop-template/` на новый адрес во всех `.html`
   (теги `canonical`, `og:url`, `og:image`, блок `ld+json`), в `robots.txt` и `sitemap.xml`.
3. Добавьте сайт в Яндекс Вебмастер и Google Search Console и отправьте `sitemap.xml`.

Пока сайт работает на `github.io/barbershop-template/`, поисковики не читают `robots.txt`
из подпапки — карту сайта можно отправить вручную в Яндекс Вебмастере.

## Что заполнить для клиента

- имена, фото и описания мастеров вместо примеров (`barbers.html`, блок «Команда» на главной);
- акции вместо примеров (`services.html`, «Спецпредложения»);
- текст о барбершопе (`about.html`, блок «Атмосфера»);
- фото работ и «до / после»;
- часы работы (можно добавить в подвал, «Контакты» и `ld+json` как `openingHours`).
